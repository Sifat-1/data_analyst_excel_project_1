# Excel-Based Loan Repayment and Risk Assessment Report
##  Project Objective
 Created a comprehensive and interactive dashboard that summarizes and visualizes key bank loan metrics, such as application volume, funding, repayment, and risk classification (Good vs Bad Loans), enabling stakeholders to monitor loan portfolio performance, identify risk trends, and support data-driven financial decision-making. This dashboard helps users quickly interpret loan health, compare loan outcomes, and evaluate financial efficiency using Excel-based analytics.
